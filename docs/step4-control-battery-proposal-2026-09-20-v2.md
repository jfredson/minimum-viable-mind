## What version 1 got wrong, in one paragraph

Version 1 reached the right destination, close Amendment A3, by an
instruction that does not exist: "run causal patching first, local, $0,
existing machinery". The review measured that no patching code exists for
this design (the only patching code in the repository is Experiment 1's,
for a different model and vocabulary; the "lesion machinery" is removal
code, not transplant code), that there is nothing to patch because the
probes have found no subspace on any seed, and that even with code and a
target, patching could reach neither outcome version 1 promised, since
"localized" needs the probe leg to agree and the registered two-instrument
null needs the matched other-agent control, which has not run. Version 1
also omitted the registered, unconditional, free blind-localization arm the
roadmap schedules for 2026-09-27; missed that the ruled deadline for
committing the pilot's training log (before this proposal was filed) had
already passed unmet; priced the redesign at three runs when every wave
here has needed a learnability run first; never cited the pre-registered
loss condition that governs this exact situation; and handed the paper a
claim, "a structural signature of ownership-specific learning", that the
amendment's own text about the input-channel lesion forbids. The
drafter's error, recorded as such.

## Recommendation

**Rule A: close Amendment A3.** The case is unchanged and survived the
review. The operative instruction changes:

1. **Do not schedule causal patching before closure.** Let it be designed
   after the localization runs below report, with its target and its null
   written down before it runs, its own Gate B, and an honest note that it
   is new code, not a free reuse.
2. **Run the localization queue already set, in the order the last review
   set it:** the registered, unconditional blind-localization arm
   (public path step 3, 2026-09-27, local, $0: the registered test of
   whether these instruments can find a centre known to be there, without
   which no null here can be read as anything but instrument failure);
   then the two runs authorised 2026-09-20 (the other-agent index at the
   eleven positions, and the standardised refit). All three are $0,
   method committed before output, each through Gate B.
3. **Decide whether the pre-registered loss condition has fired.** The
   pre-registration's loss conditions include: "No non-self cross-turn
   control can be built that is state-requiring at ceiling, then the
   differential discriminator is dead here and the honest report is 'not
   testable'." The 2026-09-17 measurement found that an ownership-free
   control and a ceiling-corrected metric are incompatible by
   construction. If John rules the condition has fired, the registered
   word for this outcome is *not testable*, and the closure text says so;
   if not, the closure text says why the control that was built does not
   meet the condition. This is his call, and version 1 should have put the
   clause in front of him.
4. **Strike "a structural signature of ownership-specific learning" from
   what the paper claims for A3.** The amendment says of the input-channel
   lesion, in its own words, that it "removes a sense organ, not a
   structure the network built", and the requirements document reserves
   the self-location name for the localized result. What A3 supports is:
   the ownership input is load-bearing for the primary battery on three
   seeds, and the matched contrast could not be run. This puts the
   approved roadmap's step 8 claim scope ("a structural signature of
   self-indexing in small constructed models") back in front of John: it
   holds only if the localization line produces a localized result before
   the paper draft; otherwise the paper's claim is the sentence above.
5. **"Partial discriminators" is not used in the closure text**, since
   none has fired; the text names which discriminators were run and what
   each returned.
6. **Housekeeping before the closure text is drafted:** commit the
   pilot's training log and trajectory record (the ruled deadline, before
   this proposal was filed, was missed; recorded in the ledger as such);
   the two open $0 checks from the pilot review (the fixed batch-split
   bias check, and the one-scored-token self-test).
7. **The closure text goes through Gate A**, both tiers, with the closure
   rule, because it is registered text.
