# MVM project site (built 2026-09-20, Pacific)

*Status: BUILT in a Cowork session on John's request; first local build and deploy are his. Companion to `site/README.md` (how it works) and `CLAUDE.md` §"Keeping the site current" (the maintenance rule).*

## Why

John: "I often find it hard to keep this all in my head and would really benefit from a front end visualizer that enabled me to quickly see where we are in the project and where we are going and what the next most valuable steps will be and what we can hope to learn from them." The Belt Equation site showed the shape that works: a structured data file the site cannot drift from, rendered as pages a reader can take in at a glance.

## Decisions (John, 2026-09-20, in-session)

1. **Home:** an Astro site at `site/` in this repo, same stack and design system as beltequation.com, deployed to a workers.dev address. Chosen over a single HTML file or a Claude artifact. Later the same day the program roadmap (`docs/program-roadmap-2026-09-20.md`) made the site the public program log from its first deploy, so the noindex tag was removed. Domain (John, 2026-09-20): `minimumviablemind.sentient-horizons.com`, a subdomain of the Sentient Horizons domain, chosen over the hyphenated `minimum-viable-mind.com` (the unhyphenated .com is taken) because MVM is downstream of Sentient Horizons, it costs nothing, and a redirect can carry the links to a standalone domain later if the project earns one. Declared as a Workers custom domain in `site/wrangler.jsonc`; the deploy creates the DNS record.
2. **Data:** a structured file `data/project.toml`, validated and exported by `scripts/export_site.py`, updated by every session that updates STATUS.md. Chosen over parsing STATUS.md directly.
3. **Scope of the first cut:** overview (goals, where we are, next steps and what each teaches, decisions waiting), the stage ladder, questions and ideas, findings, timeline, spend. All built.

## What was seeded

The data file was seeded from STATUS.md (top entries and the arc), ROADMAP.md, ROADMAP-post-removal-test.md, the public path roadmap, the step 4 proposal, the compute ledger, the Stage 3 results and the theory-instrument ledger, as of 2026-09-20. Numbers were copied, not recomputed; where the site and STATUS.md disagree, STATUS.md wins and the data file is the thing to fix.
