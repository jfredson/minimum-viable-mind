## How to mark it

Mark every sentence you would not say out loud to an expert in the field.

- **Highlight the sentence**, then **add one word** saying why:
  **unsure** (you don't know if it's true), **overclaims** (it says more than
  the results show), **unclear** (you can't tell what it means), or
  **wrong** (you think it's false). Add a few more words only if you want to.
- **On the Mac (Preview):** select the text, press ⌃⌘H to highlight, then
  right-click the highlight and choose "Add Note" for the word.
- **On the iPad (Files or Books, Markup):** use the highlighter, then write the
  word beside it with the pencil or the text tool.
- A sentence with no mark is one you would defend. You don't need to fix
  anything yourself.

**Where to save it:** in the same folder as the reading copy, as
`~/Downloads/mvm-paper-reading-copy-2026-10-25/mvm-paper-reading-copy-2026-10-25-marked.pdf`.
If you mark it on the iPad, AirDrop it back into that folder. Then tell the
master session it is there. A session that did not write the sentences will
fix or cut each one, and a second session will check the fixes.
