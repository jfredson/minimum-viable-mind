## Where the repository's instructions were not enough

I followed the instructions as written and stopped each time they ran out. In the order I met them:

1. **There is no reproduction guide.** The README describes the layout and the status but never says how to regenerate a result. `src/SETUP.md` is a one-page setup for the 2-billion-parameter pilot model (a smoke test that needs a gated model, a Hugging Face token and about 10 GB), written for a 16 GB MacBook Air, and it names the old location `~/Documents/Code/minimum-viable-mind`. The paper's Code availability sentence says all code is in the repository; the inputs the code needs are not.
2. **The libraries are not pinned where a newcomer looks.** `src/requirements.txt` and `src/requirements-interp.txt` say `torch>=2.4` and so on. The versions the paper's Methods names are pinned only in `experiments/08-successor-degree/requirements-measure.txt`, and the Python version (3.12.13) is only in a comment there. The laptop's default `python3` was 3.14.5; I had to find a 3.12 myself. `matplotlib`, which `plot_removal.py` imports, is in no requirements file (it stopped with `ModuleNotFoundError`).
3. **Scripts point at John's own working copy.** `experiments/08-successor-degree/src/run_self_tests.sh` defaults its interpreter to `$HOME/Code/minimum-viable-mind/.venv/bin/python` (I set `PY` to the clone's). `tests/inuse_cases.py` reads the 10-million-parameter checkpoints from `~/Code/minimum-viable-mind/experiments/08-successor-degree/artifacts`. In a clean clone the first quietly depends on an environment outside the clone if one exists, and the second cannot work.
4. **The inputs to the analysis scripts are ignored by git and nothing says where they live.** `analyze_removal_ci.py` (stopped with `FileNotFoundError`), `plot_removal.py`, `endpoint_a3.py`, the null-calibration and localisation scripts, and `procedure.py model` all need files under `artifacts/` or checkpoints. The checkpoint checksums are listed (`out-reruns-10m/checkpoints.sha256-md5.txt`) with no location.
5. **Some figures are cited to a place that does not contain them.** The "17 of 26 layers" figure is cited to Methods, which has no such sentence (E1-25). "Activation ratios 0.92 to 0.99" and the 17-of-26 figure survive only in `STATUS-archive.md` (E1-30). The standardised-refit margin of 0.000484 is cited to a findings file that does not state it; it is in the closure block and the review ledger (E6-22).
6. **Two sets of numbers sit side by side in the same file with no marker saying which is current.** `gate1-curriculum-findings.md` certifies the twelve-turn grammar and then, further down, says that grammar "did not test self-indexing at all"; the figures the paper takes from it are the superseded ones (E6-23). `rt09-reflexivity-findings.md` reports first-pass numbers that `thresholds.md` later supersedes (E1-24).
7. **The readiness checklist's own ordering was not met.** It says steps 2 and 3 wait for the measurement rehearsal's result to be in the paper. John told me to start now; I flag it so the second pass is not forgotten.
